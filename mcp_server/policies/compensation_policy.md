# Blue Horizon Airlines — Passenger Compensation Policy (v1, illustrative)

This is a simplified policy

## When is a passenger entitled to compensation?
Compensation is only issued if the flight is `disrupted` or `cancelled`
at the time compensation is issued. Compensation is not allowed for a
`scheduled` flight or a minor `delayed` flight under two hours.

## Approval thresholds
- **Under 300 USD**: the agent can issue it directly (status = approved automatically).
- **300 USD or more**: explicit supervisor approval is required before
  issuing (elicitation) — because of the financial impact on the company.

## Fare classes
- Business/First class: compensation amounts tend to be higher due to
  ticket price, but the base threshold (300 USD) is still what determines
  whether approval is needed, not the fare class itself.

## Accountability
Every compensation record must include `issued_by` (employee name or ID),
which becomes part of the audit trail for any later review.
